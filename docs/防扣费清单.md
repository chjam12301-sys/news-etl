## 护栏一：代码层（已内置，无需操作）

`app/storage_guard.py` 已接入流水线：

| 阈值 | 行为 |
|---|---|
| 占用 ≥ 6.4 GB（80%） | 日志警告 |
| 占用 ≥ 8 GB（100%） | **抛异常拒绝写入**，任何文件都传不上去 |

**这意味着：即使代码出 bug 疯狂上传，R2 也绝对不会超过 8GB。**
超出 10GB 才收费，而我们在 8GB 就停了 → **费用恒为 0**。

其他内置限制：
- `timeout-minutes: 25` —— 单次运行超 25 分钟被杀
- `concurrency: group: daily-news` —— 不会并发叠加
- 每天 1 次 cron，7 主题 × 1 篇 = 70 次 LLM 调用 + 70 段音频

## 护栏二：账户层（建议你手动设，约 3 分钟）

### 1️⃣ GitHub 预算告警（防 Actions 意外超量）

**https://github.com/settings/billing/budgets**

- 点 **Set a budget**
- 填 **10**（美元）—— 设一个你绝不会心疼的数字
- 勾选 **「Stop workflows when budget is exceeded」**（可选但推荐）
- 同时勾 **「Send email alerts」**

> 这样即使出现死循环跑满额度，GitHub 也会主动停掉并邮件通知你。

### 2️⃣ Cloudflare R2 付费告警

R2 控制台 → **Overview** → 往下拉 → **Notifications / Billing alerts**

- 设为「用量达到 80% 时通知」
- 填你的邮箱

> R2 超出 10GB 后按 $0.015/GB/月 计费 ——虽然我们的代码在 8GB 就拦住了，
> 但多一道告警更安心。

### 3️⃣ DeepSeek 余额告警（可选）

**https://platform.deepseek.com/usage**

DeepSeek 充值后一般不会自动扣款，但可以关注剩余额度。

## 一键回滚（万一真产生费用）

如果账单出现金额，立刻：

1. **删掉 GitHub Actions**：仓库 → Settings → Actions → Disable
2. **暂停 R2**：Cloudflare R2 → 删除 bucket 或降级订阅
3. **查明细**：https://github.com/settings/billing

三个动作都不会影响已生成的内容（数据在 R2/Neon 里，跟计费无关）。
