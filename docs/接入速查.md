## 三个请求，够了

```javascript
const BASE = "https://cdn.jsdelivr.net/gh/chjam12301-sys/news-etl@main/content";

// ① 首页列表
const index = await fetch(`${BASE}/data/index.json`).then(r => r.json());
index.latest.versions.en   // 英语5 条（level 1→5）
index.latest.versions.ja   // 日语 5 条
index.levels               // 等级字典，启动时缓存

// ② 详情（点进某篇）
const detail = await fetch(item.detail_url).then(r => r.json());
detail.paragraphs    // 段落，分段渲染
detail.vocab        // 词汇表，做练习题
detail.text         // 🔴 逐词高亮用这个
detail.timeline     // 逐词时间轴

// ③ 播放
player.src = item.audio.url;
```

## 🔴 唯一容易错的地方

```javascript
// ✅ 对
detail.text.slice(w.cs, w.ce) === w.w

// ❌ 错 —— body 有段落换行，多段正文一定跳字
detail.body.slice(w.cs, w.ce)
```

`text` 是压平成单行的版本，`cs/ce` 就是按它算的。

---

## 时间轴字段

| 字段 | 含义 |
|---|---|
| `sm` / `em` | 起止毫秒（播放器直接用） |
| `cs` / `ce` | 在 `text` 中的字符区间 |
| `w` | 词文本（含标点） |
| `si` | 句子序号 |

**保证**：`sm` 与 `cs` 都严格单调递增、不重叠、100% 覆盖全文（不含空格）。

## 高亮实现

```javascript
function activeIndex(tl, t) {          // t = 当前毫秒
  let lo = 0, hi = tl.length - 1, ans = -1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (tl[mid].sm <= t) { ans = mid; lo = mid + 1; }
    else hi = mid - 1;
  }
  return ans;
}

function render(detail, t) {
  const w = detail.timeline[activeIndex(detail.timeline, t)];
  if (!w) return;
  range.setStart(w.cs, w.ce);          // 在 detail.text 上标range
}

// 倍速：sm/em 同比例缩放，无需重新请求
// 点词跳转：player.currentTime = w.sm / 1000
```

## 等级切换（零额外请求）

同一篇文章有 10 个等级（5 英 + 5 日）。用按日索引直接取：

```javascript
const day = await fetch(`${BASE}/data/${index.latest.date}/index.json`)
  .then(r => r.json());

// 切到日语 N3：day.versions.ja.ja_n3
// 里面每条都是 ListItem，结构与首页相同（含自己的 detail_url / audio.url）
const item = day.versions.ja.ja_n3.find(x => x.article_id === currentId);
```

## ⚠️ CDN 缓存

| 内容 | 会变吗 | 缓存策略 |
|---|---|---|
| `data/index.json` | 每天更新 | 5–15 分钟，或加 `?t=${Date.now()}` |
| 详情 JSON | **不变** | 按 `version_id` 永久缓存 |
| 音频 | **不变** | 落盘永久缓存 |
